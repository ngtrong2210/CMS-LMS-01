TÀI LIỆU DÙNG TRONG VISUAL STUDIO CODE

Chạy và quản lý project bằng Terminal của VS Code

Mở hai Terminal riêng: một Terminal chạy API ASP.NET Core và một Terminal chạy giao diện Vue/Vite. Mỗi khối lệnh bên dưới có thể sao chép và dán trực tiếp vào PowerShell của VS Code.

Mở website Mở Swagger API

Bắt đầu

Chạy project trong VS Code

Chọn Terminal → New Terminal, sau đó dùng nút Split Terminal để mở Terminal thứ hai.

1

Mở project bằng VS Code

Chạy từ PowerShell hoặc hộp thoại Run của Windows.

code "G:\0.0TOOL\CODEX\CMS-LMS-VueJS"
2

Terminal 1 — Backend

Chạy API bằng launch profile http trên cổng 7001.

cd "G:\0.0TOOL\CODEX\CMS-LMS-VueJS\src\LmsCms.Api"
dotnet run --launch-profile http

Thành công khi thấy: Now listening on: http://localhost:7001

3

Terminal 2 — Frontend

Chạy Vue/Vite trên cổng 5173.

cd "G:\0.0TOOL\CODEX\CMS-LMS-VueJS\frontend"
npm run dev

Thành công khi thấy: Local: http://localhost:5173/

Cài thư viện frontend lần đầu

Chỉ cần chạy khi mới tải project hoặc sau khi file package.json thay đổi.

cd "G:\0.0TOOL\CODEX\CMS-LMS-VueJS\frontend"
npm install

Kết thúc

Dừng project

Cách thông thường

Chọn từng Terminal đang chạy rồi nhấn:

Ctrl+C

Tắt cưỡng chế cả backend và frontend

Dùng khi đã đóng Terminal nhưng cổng 7001 hoặc 5173 vẫn còn bị chiếm.

Get-NetTCPConnection -LocalPort 7001,5173 -State Listen -ErrorAction SilentlyContinue |
    Select-Object -ExpandProperty OwningProcess -Unique |
    ForEach-Object { Stop-Process -Id $_ -Force }

SQL Server

Khởi tạo hoặc cập nhật database

Chỉ chạy khi cần tạo schema, stored procedure và dữ liệu mẫu. Không ghi mật khẩu thật vào tài liệu hoặc Git.

Thiết lập connection string trong Terminal hiện tại

$env:ConnectionStrings__BootstrapConnection="<CHUOI_KET_NOI_SQL_SERVER>"
$env:ConnectionStrings__DefaultConnection="<CHUOI_KET_NOI_DATABASE_LMSCMS_DB>"

cd "G:\0.0TOOL\CODEX\CMS-LMS-VueJS\src\LmsCms.Api"
dotnet run --launch-profile http -- --init-db

Không chạy lệnh này trong lúc backend khác đang giữ cổng 7001.

Chẩn đoán

Kiểm tra cổng và tiến trình

Kiểm tra cổng 7001 và 5173

Get-NetTCPConnection -LocalPort 7001,5173 -State Listen -ErrorAction SilentlyContinue |
    Select-Object LocalAddress,LocalPort,OwningProcess

Kiểm tra website và API

Invoke-WebRequest "http://localhost:5173/login" -UseBasicParsing
Invoke-WebRequest "http://localhost:7001/swagger/index.html" -UseBasicParsing

Hỗ trợ

Lỗi thường gặp

Required argument missing for --project

Nguyên nhân: lệnh dừng ngay sau --project và chưa có đường dẫn project.

Khắc phục: cd vào src\LmsCms.Api, sau đó chạy dotnet run --launch-profile http.

Could not read package.json

Nguyên nhân: chạy npm run dev ở thư mục gốc.

Khắc phục: cd vào thư mục frontend trước khi chạy npm.

Hosting failed to start

Thường do cổng 7001 đã có backend khác sử dụng. Nhấn Ctrl + C ở Terminal cũ hoặc dùng lệnh tắt cưỡng chế.

oh-my-posh is not recognized

Đây là lỗi cấu hình giao diện PowerShell, không phải lỗi project.

code $PROFILE

Trong file profile, dùng điều kiện:

if (Get-Command oh-my-posh -ErrorAction SilentlyContinue) {
    oh-my-posh init pwsh | Invoke-Expression
}
